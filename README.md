# ASHDELVE – Pixel Editor

Nástroj na překreslení obrázků hry **ASHDELVE** (studio Maxikus0984).

## Stažení (Windows)
**[⬇ Stáhnout AshdelveEditor-Windows.zip](https://github.com/flutkamaxmilian-sys/ashdelve-editor/releases/latest/download/AshdelveEditor-Windows.zip)**

1. Rozbal celý ZIP a spusť `AshdelveEditor.exe` (SmartScreen: „Další informace“ → „Přesto spustit“).
2. Klikni na obrázek, který chceš překreslit.
3. Vlevo kreslíš ve stejné velikosti jako originál, vpravo je originál jako předloha.
4. `Ctrl+S` uloží. Když jsi hotový, klikni **„Zabalit pro Maxe“** a pošli vzniklý
   `Moje_obrazky_pro_Maxe.zip`.

Původní grafika: [Kenney](https://kenney.nl) – Tiny Dungeon, Tiny Town (CC0). Písmo VT323 (SIL OFL).
